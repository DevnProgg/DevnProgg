Approach

I currently design and build loan management systems with automatic billing, payment tracking and data-driven decision support. These tools have to work on limited hardware and intermittent connectivity, so I prioritise performance, simplicity and reliability.

My background spans React applications, RESTful APIs and backend systems in JavaScript and Python, with growing specialisation in high-performance services using Go. I also build offline-first desktop applications with Tauri, React and SQLite.

Beyond fintech, I explore AI, computer vision and data-driven automation, including vehicle detection, chatbots and predictive systems. I'm interested in how AI can augment human work rather than replace it. Long term, I'm working toward software architecture, with a focus on system design, scalability, security and cloud-native architecture.
